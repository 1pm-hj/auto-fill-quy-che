# Auto Fill Quy Chế HUST

Tiện ích tự động điền đáp án bài thi Quy chế trên Microsoft Forms dành cho sinh viên ĐHBK Hà Nội.

---

## 🚀 Hướng dẫn cài đặt và sử dụng

### 1. Tải tiện ích về máy
- Bấm vào nút **Code** (màu xanh ở góc trên bên phải trang này).
- Chọn **Download ZIP**.
- Giải nén file `.zip` vừa tải về ra một thư mục trên máy tính.

### 2. Cài đặt vào trình duyệt (Chrome / Cốc Cốc / Edge)
- Mở trình duyệt và truy cập đường dẫn: `chrome://extensions/` (đối với Cốc Cốc là `coccoc://extensions/`).
- Bật công tắc **Chế độ dành cho nhà phát triển** (*Developer mode*) ở góc trên bên phải màn hình.
- Bấm vào nút **Tải tiện ích đã giải nén** (*Load unpacked*) ở góc trên bên trái.
- Chọn đến thư mục bạn vừa giải nén ở Bước 1.

### 3. Cách sử dụng
- Mở trang bài kiểm tra Microsoft Forms.
- Bấm vào biểu tượng tiện ích **Auto Fill Quy chế** trên thanh công cụ trình duyệt.
- Bấm nút **Điền đáp án** và chờ tiện ích tự động chọn đúng 200/200 câu.
